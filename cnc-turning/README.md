# 数控车削编程助手

FANUC 车床（0i-T）编程教学工具。单文件 Web 应用，零依赖、零构建，双击 `app.html` 即用。

规划与口径见 [`docs/功能模块规划.md`](docs/功能模块规划.md)。

## 使用

双击 `app.html`。所有功能纯本地运算，不上传任何数据。

工件卡改动即时生效并写入浏览器 localStorage；换机器或交作业时用「导出工件卡」带走，批改时再导入，保证判定口径一致。

## 开发命令

```bash
node tests/run-tests.js                       # 纯函数·解析器·数据层断言，必须 0 失败
node tools/smoke.js                           # 真实无头 Edge 端到端冒烟（1200×900）
node tools/smoke.js --width 500                # 窄视口：验工件卡两列堆叠与横向溢出
node tools/smoke.js --shot tmp/shot.png        # 额外存一张截图
node tools/smoke.js --panel explain --shot tmp/x.png   # 指定面板截图（解释/编辑器/参数…）
```

冒烟依赖本机 Edge：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，不需要 npm 安装任何东西。

## 必须守住的约定

1. **单文件、零依赖**：不引 CDN、不引图标库、不拆模块；`app.html` 里出现 `src="http` 即视为违规（有断言拦）。
2. **体积闸门 600 KB**：由断言检查。帮助配图一律内联 SVG 线稿，**禁止嵌 PNG base64**（铣削版就是被 11 张截图占掉 80.5%）。
3. **数据只有一处真相**：材料、刀具、螺纹规格都在数据层，其他面板只通过查表取值，不各自维护默认值。
4. **规则判不了就说判不了**：缺工件卡字段时进 NA 状态并列出来，不允许静默返回"通过"。
5. **0 失败才算完成**：`run-tests.js` 与 `smoke-m0.js` 全绿才允许发版。
6. **无障碍基线**：表单控件必须有 `label[for]`，导航有 `aria-label`，状态区是 `aria-live`（均有断言）。
